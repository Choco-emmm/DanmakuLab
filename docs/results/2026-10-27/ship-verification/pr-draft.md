## Summary

大量慢观众会占满同步发送池；单机房间也不能直接向另一JVM的观众广播。本次保留同步local基线，提供容器异步输出、可选fair调度和Redis Pub/Sub双节点路径。

```text
输入校验与节点内限流
  ├─ local → direct / fair
  └─ redis → 有界发布FIFO → PUBLISH → 各节点有界接收FIFO → fair
                                                   ↓
                               本地连接邮箱 → 单连接在途异步写 → 观众
```

- 每房间轮转批次、房间/全局预算；每连接单在途，完成回调才释放预算，多个慢读不占共享提交线程等待。
- 来源节点只订阅回流，不额外直发；保留来源messageId/originNodeId/runId/房间实例/序号。accepted表示Redis执行确认，unknown不自动重发。
- 归档T2～T6与双节点正式/失败原始数据、统计工具、中文学习和运行说明。本分支包含未合并PR #2的有界邮箱前序提交，不自动修改其状态。
